此分支从 `8bd2f31` 建立独立工作树；原候选及其 4183 预览保持不变。第一阶段只交付如意洲、山地两个可验证样板，不把七十二景误称为七十二座现存建筑或七十二处已完成近景。

## 资料和表达边界

- `K36`：故宫博物院《御制避暑山庄三十六景诗》，核对康熙三十六景的题名和次序：[资料页](https://www.dpm.org.cn/ancient/hall/160060.html)。
- `Q36`：故宫博物院《紫禁城》2023 年第 8 期相关文章第 100 页“避暑山庄乾隆三十六景”附录，核对乾隆三十六景的题名和次序：[PDF](https://www.dpm.org.cn/Uploads/File/2023/08/29/u64ed5903a6eca.pdf)。特别核对了“宿云檐”，不采用来源不明的异写。
- `RY12`：避暑山庄景区的如意洲介绍，核对始建于康熙四十二年、十二景名单及中轴／东西南北的分组：[资料页](https://www.bishushanzhuang.com.cn/index.php/Scenic/spot_view/id/37.html)。区域图标记仅把该分组转换成可探索的相对位置，不是精确旧址或 GPS。
- `NPM-LOTUS`：国立故宫博物院“治园如治国”展览资料，核对金莲映日在延薰山馆前种植金莲的由来：[资料页](https://theme.npm.edu.tw/exh111/ChengdeSummerResort/ch/page-2-2.html)。
- `RESORT-SIMIAN`：[四面云山介绍](https://www.bishushanzhuang.com.cn/index.php/Scenic/spot_view/id/48.html)，用于核对高处亭与十六柱的描述；始建年份资料有异，不在游客文案中定论。
- `RESORT-CHUIFENG`：[锤峰落照介绍](https://www.bishushanzhuang.com.cn/index.php/Scenic/spot_view/id/158.html)，用于核对园外磬锤峰借景。
- 原有 11 景的描述以原项目 `guideScripts` 中已核对的资料为基础，现统一改写为完整叙述；原始 11 条来源 URL 由先前版本的 Git 历史和项目研究记录追溯，**不在游客页面渲染**。

`public/atlas-data.json` 保留 `sourceRefs` 代码而不含外部景点 URL。72 条逐景原创介绍来自 `sources/research/scene-72/` 中的康熙、乾隆游客文案；对应研究记录和来源表只留在开发目录。区域按历史景观分组表达，不是精确定位；实地保存、复建与开放状态均未逐景核实，未有画面的景点标记“筹备中”。“已游览”只表示用户在本作品中打开过该景点画面，存储在本机浏览器。

早先的康熙第 1–12 景研究草稿仍在 `sources/research/kangxi-01-12.json`，完整版本已按现有 `k01`–`k36`、`q01`–`q36` 编号映射接入。康熙第 19 景旧图鉴写“暖流喧波”，现依研究校为“暖流暄波”，并保留有出处的“暖溜暄波”异写。别名的关系提示一并显示，避免把所属寺院、亭名误作同义景名。尤其“北枕双峰”的远山金山不可误作湖区金山岛，“西岭晨霞”属于如意洲西路；如意湖是西岸亭景，不当作如意洲，青雀舫是历史御舟，不画为固定楼阁。

## 美术

本阶段单独生成如意洲湖岛、山地云岭、无暑清凉、延薰山馆、水芳岩秀五幅原创新画，并将烟雨楼近景人物、船只重绘入同一幅画；为长卷两处明显地貌接缝重新绘制宫殿区、平原区画面左缘。运行时 WebP 在 `public/art/`，原始 PNG 在 `sources/region-art/`。未使用任何景区或参考作品的图片。

- 如意洲提示词要点：俯瞰湖岛，中轴院落与四面园景可辨，湖水、柳树、莲叶及远山，清代工笔矿物色、旧宣纸，宽幅长卷，禁止文字、现代物件和现成作品复制。
- 山地提示词要点：四面云山亭所在山地，松石曲径、层峦云海、远处园外借景的磬锤峰，工笔细线与赭青矿物色，宽幅长卷。
- 无暑清凉提示词要点：如意洲中轴宫苑的写意近观，克制的木构、庭院、柳荫与莲池，明确是历史题名的艺术想象而非现状照片。
- 延薰山馆提示词要点：七开间理政建筑、前抱厦、前后游廊，以夏荫下的院落和湖水远景与无暑清凉区别；仍是艺术想象而非精确复原。
- 水芳岩秀提示词要点：较深处的读书殿宇，前后伸展的空间、池水与石景相对，突出水清与岩秀；画中人物静止。
- 烟雨楼近景提示词要点：保留楼、水、山的原图布局，将静立人物和舟船融入同一画面，统一笔触与水线，不另叠贴图。
- 宫殿接缝提示词要点：以宫殿画为底，只在左缘加入可与金山湖水相连的湖岸，过渡到石坪；保留丽正门和正殿的位置。平原接缝提示词要点：以平原画为底，只在左缘加入逐渐收束到土径的宫殿石坪，保留山地、池水和远处建筑。

生成图具有艺术表达性质，不能从图像反推建筑旧址、现存结构或准确行走路线。画中人物和船保持原项目的静止约束。

## 已实现与待补

主卷可进入如意洲和山地的二维区域画面，拖动浏览、在画上与底部列表选景；近景返回区域原位，再返回主卷原位。区域和近景承接原卷的昼夜晴雨，区域工具条提供可见控制。入口动画可跳过。图鉴可搜景名和别名，按朝代、区域、游览状态筛选。未完成景点没有可误触的“近景”入口。

本阶段区域近观完成无暑清凉、延薰山馆、水芳岩秀、四面云山、锤峰落照。整个作品目前有 9 处历史题名可进入近景（6 处沿用原近景，3 处是新绘如意洲近景）。其余如意洲 9 景有史料相对方位和逐景文字，画面仍筹备中；72 景文字资料完成不表示 72 幅画面完成。原有 11 景说明已扩充为较完整的段落；烟雨楼近景人物、舟船现位于同一画作中，夜雨浓雾也已减淡。真实手机、低端设备性能和实地现状未核验。

## 本地浏览器验收

在 Mac 的 Chrome 中对构建预览 `http://127.0.0.1:4185/` 测试：原有 11 个长卷景点均可进入近景并返回原画位置；键盘 Tab 保持在近景对话层，Escape 返回且恢复焦点；手机模拟 360、390、430 像素均无页面横向溢出，导航可横滑，缩放按钮 44×44 像素；触摸拖动画面和双指缩放实际改变画卷位置与高度。区域从主卷进入、选景、近观、逐层返回的位置恢复、昼夜雨继承、图鉴搜索与筛选均通过。新增延薰山馆、水芳岩秀近景实际加载了各自画作；浏览器逐个打开图鉴 72 行并核对景名、正文长度与 9 景可游览／63 景筹备状态。游客页面渲染外链仅有正式 GitHub 仓库、音乐来源和许可，景点资料链接只见于本开发文档。`node --check`、`npm run build`、`git diff --check` 均通过。
