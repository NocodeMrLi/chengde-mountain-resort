## 美术

本阶段单独生成如意洲湖岛、山地云岭和无暑清凉近景三幅原创新画，并将烟雨楼近景人物、船只重绘入同一幅画；为长卷两处明显地貌接缝重新绘制宫殿区、平原区画面左缘。运行时 WebP 在 `public/art/`，原始 PNG 在 `sources/region-art/`。未使用任何景区或参考作品的图片。

- 如意洲提示词要点：俯瞰湖岛，中轴院落与四面园景可辨，湖水、柳树、莲叶及远山，清代工笔矿物色、旧宣纸，宽幅长卷，禁止文字、现代物件和现成作品复制。
- 山地提示词要点：四面云山亭所在山地，松石曲径、层峦云海、远处园外借景的磬锤峰，工笔细线与赭青矿物色，宽幅长卷。
- 无暑清凉提示词要点：如意洲中轴宫苑的写意近观，克制的木构、庭院、柳荫与莲池，明确是历史题名的艺术想象而非现状照片。
- 烟雨楼近景提示词要点：保留楼、水、山的原图布局，将静立人物和舟船融入同一画面，统一笔触与水线，不另叠贴图。
- 宫殿接缝提示词要点：以宫殿画为底，只在左缘加入可与金山湖水相连的湖岸，过渡到石坪；保留丽正门和正殿的位置。平原接缝提示词要点：以平原画为底，只在左缘加入逐渐收束到土径的宫殿石坪，保留山地、池水和远处建筑。

生成图具有艺术表达性质，不能从图像反推建筑旧址、现存结构或准确行走路线。画中人物和船保持原项目的静止约束。

## 已实现与待补

主卷可进入如意洲和山地的二维区域画面，拖动浏览、在画上与底部列表选景；近景返回区域原位，再返回主卷原位。区域和近景承接原卷的昼夜晴雨，区域工具条提供可见控制。入口动画可跳过。图鉴可搜景名和别名，按朝代、区域、游览状态筛选。未完成景点没有可误触的“近景”入口。

本阶段区域近观只完成无暑清凉、四面云山、锤峰落照。整个作品目前有 7 处可进入近景（6 处沿用原近景，1 处是新绘无暑清凉）。其余如意洲 11 景有史料方位和文字，画面仍筹备中；更多区域与七十二景逐景叙述要按同样的证据门槛逐批制作。原有 11 景说明已扩充为较完整的段落；烟雨楼近景人物、舟船现位于同一画作中，夜雨浓雾也已减淡。真实手机、低端设备性能和实地现状未核验。

## 本地浏览器验收

在 Mac 的 Chrome 中对构建预览 `http://127.0.0.1:4185/` 测试：原有 11 个长卷景点均可进入近景并返回原画位置；键盘 Tab 保持在近景对话层，Escape 返回且恢复焦点；手机模拟 360、390、430 像素均无页面横向溢出，导航可横滑，缩放按钮 44×44 像素；触摸拖动画面和双指缩放实际改变画卷位置与高度。区域从主卷进入、选景、近观、逐层返回的位置恢复、昼夜雨继承、图鉴搜索与筛选均通过。游客页面渲染外链仅有正式 GitHub 仓库、音乐来源和许可，景点资料链接只见于本开发文档。`node --check`、`npm run build`、`git diff --check` 均通过。
