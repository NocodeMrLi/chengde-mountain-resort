# 2026-10-02 本地候选验收记录

本记录对应 `codex/experience-upgrade-20261002` 工作树。候选仅在本机运行，尚未推送或更新公开站点。

## 本轮差距与处理顺序

1. 近景进入以前只有圆形揭幕，烟雨楼的近景失去了全景里的人与船。本轮加入景点锚点镜头推进、近景前后层的轻微视差，并在烟雨楼近景放回静止人物与画舫。
2. 近景原来没有跟随全景的夜色与烟雨；现在近景也随状态改变。拨云按钮保留已有雾散动画，增加可读的切换状态。
3. 手机底部的景点导航缺少横向滚动提示，缩放按钮触控区域偏小；现在增加提示、滚动末端反馈、44 像素触控目标，以及双指缩放。
4. 近景焦点以前会留在被遮挡的全景热点。现在打开近景时隔离背景、转移焦点，关闭后回到来源控件；图片加载失败时显示重试或返回入口。
5. 首屏六幅长卷 PNG 共 18,649,731 字节，现运行时使用视觉检查过的 WebP 共 3,396,786 字节。原 PNG 保留在仓库中，便于后续美术修订。

## 本地验证

- `node --check app.js`、`npm run build`、`git diff --check` 均通过。
- Chrome 本机自动化逐一进入和退出 11 个景点，检查了近景图片、焦点、背景隔离与返回位置；全部通过。
- 在 360、390、430 CSS 像素宽度下检查导航可滚动、页面不横向溢出、近景按钮留在视口内、缩放按钮为 44×44 像素。
- Chrome 模拟触摸拖动画卷，摄像机位置从 902 移至 1288；模拟双指放大后画卷高从 844 变为 1223.8 像素。**这些是浏览器模拟触摸，并非真机测试。**
- 近景的夜色与烟雨、拨云后的雾层消失、资源加载失败时的重试、键盘 Tab 循环与 Escape 返回均通过。
- 五处画卷接缝按桌面、360／390／430 宽度、再回桌面，以及 85%／100%／145% 缩放共保存 75 张截图。未见空白图或固定在视口中线的亮竖条。
- 用 Chrome 打开构建后的 `dist/` 预览，检查入口、烟雨楼近景、拨云、返回与手机布局。入口和游览页的 GitHub 图标已在 390 像素宽度实际点击，均于新标签打开正式仓库。
